# NexusRail UI/UX Enhancement & Order ID Modernization Plan

## 1. Executive Summary & Goals
This plan details the architecture, design tokens, component upgrades, and backend implementations for:
1. **Glassmorphism Design System**: Authentic translucent frosted-glass surfaces (`backdrop-blur-xl`, `border-white/10`, layered box-shadows, subtle ambient gradients) applied cohesively across all pages.
2. **Global Theme & Effects Customizer**: A refined navbar control supporting 3 presets (`Dark Glass`, `Light Glass`, `Black & Gold`), toggleable ambient background effects, and motion/animation preference controls with `localStorage` persistence.
3. **Professional Order IDs (`NR-YYYY-XXXXXX`)**: Replacing random hashes and raw IDs with sequential, human-readable, collision-proof order references generated by an atomic MongoDB counter (`$inc`), backed by safe migration and strict access authorization.

## 2. Architecture & Affected Files

### Backend (Order ID Engine & APIs)
- `apps/api/src/services/orderSequence.ts` *(New)*:
  - `OrderSequenceService.getNextOrderNumber()`: Atomic sequence via MongoDB `counters` collection (`findOneAndUpdate` with `$inc: { seq: 1 }`).
  - `OrderSequenceService.backfillLegacyOrders()`: Safe migration for historical records.
- `apps/api/src/routes/orders.ts`:
  - Integrate `OrderSequenceService.getNextOrderNumber()` on order creation.
  - Enforce user authorization (`user_id: req.user!.id`) on all lookups.
- `apps/api/src/services/stripe.ts`:
  - Use `OrderSequenceService.getNextOrderNumber()` for Stripe checkout sessions.
- `apps/api/src/routes/agent.ts`:
  - Enhance order ID matching regex for `NR-YYYY-XXXXXX` and use `OrderSequenceService`.
- `apps/api/src/services/mongo.ts`:
  - Ensure `counters` collection and indexes are initialized.

### Frontend (Theme Tokens & Glassmorphism)
- `apps/web/src/components/ThemeProvider.tsx`:
  - Expand `ThemeContext` to manage:
    - `preset`: `'dark-glass' | 'light-glass' | 'black-gold'`
    - `effects`: `'ambient' | 'minimal'`

  - Apply `data-theme`, `data-effects`, and `data-motion` attributes to `document.documentElement`.
- `apps/web/src/app/globals.css`:
  - Define CSS custom properties for glass backgrounds, frosted borders, and ambient gradients per theme.
  - Add `@media (prefers-reduced-motion: reduce)` and `[data-motion="reduced"]` overrides to suppress animations.
- `apps/web/src/components/ThemeCustomizerModal.tsx` *(New)*:
  - Polished frosted-glass modal / popover accessible from navbar with preset preview chips, effects switches, and motion toggles.
- `apps/web/src/components/SiteHeader.tsx`:
  - Replace basic toggle button with Theme Customizer trigger (with tooltip & icon).
  - Add frosted glass styling (`backdrop-blur-xl bg-opacity-70`).
- `apps/web/src/components/AppShell.tsx`:
  - Include ambient background layer with floating soft orbs / gradient mesh when `effects="ambient"`.
- `apps/web/src/app/orders/page.tsx`:
  - Display `NR-2026-XXXXXX` with copy button, frosted glass cards, and status tags.
- `apps/web/src/app/receipt/page.tsx`:
  - Format invoice order number with copy button and updated design tokens.
- `apps/web/src/app/swap/page.tsx`:

## 3. Risk Assessment & Mitigations

| Risk | Impact | Mitigation |
| :--- | :--- | :--- |
| **Concurrent order creation collision** | High (Duplicate key error) | Use MongoDB atomic `findOneAndUpdate` with `$inc` on `seq`. Uniqueness index on `order_number` prevents any race condition. |
| **Historical orders breaking** | Medium (404 on old links) | Lookups use `$or: [{ id }, { order_number: id }]` so old IDs (`NR-1048`) and new IDs (`NR-2026-000001`) resolve identically. |
| **Glassmorphism contrast degradation** | Medium (Accessibility issue) | Maintain strict text contrast ratios (≥4.5:1) by layering opaque text tokens and dark backing underneath text containers. |
| **Heavy GPU usage from blur/particles** | Low (Mobile lag) | Restrict blur to `16px-24px`, use CSS hardware-accelerated transforms (`translate3d`), and provide an instant toggle to turn off effects. |

## 4. Acceptance Criteria & Verification
1. `getNextOrderNumber()` generates sequential references like `NR-2026-000001`, `NR-2026-000002`.
2. Concurrent order creation produces strictly unique numbers without collisions.
3. Navbar theme customizer switches between Dark Glass, Light Glass, and Black & Gold instantly, persisting across page reloads.
4. Glassmorphism cards have readable typography, frosted blur, and smooth hover micro-interactions.
5. Reduced motion setting disables decorative floating animations and respect OS preferences.
6. Order references display with copy buttons on `/orders`, `/receipt`, `/activity`, and `/checkout`.
7. `pnpm --filter web build` and API tests pass with zero regressions.
8. Zero remote pushes or production deployments without explicit user consent.
